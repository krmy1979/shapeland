# Shapeland · a world by Shirel Yitzhak

משחק תלת־ממדי לילדים: בונים מצורות, מעצבים בית, מטיילים באי, בעיירה ובאזור בהשראת אשקלון. אנגלית מדוברת, חשבון וניהול כסף מוטמעים בתוך המשחק עצמו.

## איך מריצים
1. פותחים את התיקייה `Shapeland` ב־VS Code (File ← Open Folder).
2. מתקינים את התוסף **Live Server**: בלשונית Extensions (Ctrl+Shift+X) מחפשים Live Server ולוחצים Install.
3. לוחצים ימני על `index.html` ובוחרים **Open with Live Server**.

אפשר גם פשוט לפתוח את `index.html` בדפדפן בלחיצה כפולה.

## חשוב לדעת
- **משחק עם חברות** עובד כרגע רק בגרסה שמפורסמת ב־Claude. כשפותחים מהמחשב, המשחק עובד במצב "משחק לבד". השלב הבא הוא שרת קטן (Firebase או Supabase) ואתר ב־GitHub Pages.
- **ההתקדמות נשמרת בדפדפן** של המכשיר שעליו משחקים.
- **בטיחות:** אין צ'אט חופשי, אין מיקום אמיתי, ואין מקומות פרטיים. המקומות באזור אשקלון ציבוריים ומצוירים בסגנון צעצוע.

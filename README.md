# Shapeland · a world by Shirel Yitzhak

משחק תלת־ממדי לילדים: בונים מצורות, מעצבים בית, מטיילים באי, בעיירה ובאזור בהשראת אשקלון. אנגלית מדוברת, חשבון וניהול כסף מוטמעים בתוך המשחק עצמו.

## איך מריצים
1. פותחים את התיקייה `Shapeland` ב־VS Code (File ← Open Folder).
2. מתקינים את התוסף **Live Server**: בלשונית Extensions (Ctrl+Shift+X) מחפשים Live Server ולוחצים Install.
3. לוחצים ימני על `index.html` ובוחרים **Open with Live Server**.

אפשר גם פשוט לפתוח את `index.html` בדפדפן בלחיצה כפולה.

## מערכת סגורה לחברים (Firebase)
- **אזור הורים:** `parent.html`. נכנסים עם Google, פותחים חשבון שחקן לילד (מקבלים קוד שחקן ו־PIN), רואים התקדמות וקובעים זמן משחק יומי.
- **חבורה:** הורה פותח חבורה ומקבל קוד (למשל SL-7KQ2). הורים אחרים מבקשים להצטרף עם הקוד, ומנהל החבורה מאשר כל ילד בנפרד.
- **כללי אבטחה:** `database.rules.json` (מפורסמים ב־Realtime Database). רק ילדים מאושרים רואים ושומעים אחד את השני.
- **הגדרות החיבור:** `js/firebase-config.js` (פרויקט shapeland-85461).
- `js/21-cloud.js`: כניסת ילדים, שמירה בענן, זמן משחק ומשחק משותף. `js/parent.js`: אזור ההורים.

## חשוב לדעת
- **משחק עם חברות** עובד דרך Firebase, באתר https://krmy1979.github.io/shapeland ובהרצה מהמחשב.
- **ההתקדמות נשמרת בענן** לכל ילד שנכנס עם קוד, כך שאפשר להמשיך מכל מכשיר.
- **בטיחות:** אין צ'אט חופשי, אין מיקום אמיתי, ואין מקומות פרטיים. המקומות באזור אשקלון ציבוריים ומצוירים בסגנון צעצוע.

## קבוצות חברים (בלי אישור הורים לכל ילד)
- לכל ילד יש **קוד חבר** אישי (F-XXXXX). רואים אותו באזור ההורים ובמשחק בכפתור 👫.
- הילד פותח קבוצה במשחק ומזמין חברים לפי הקוד שלהם. החבר מחליט אם להצטרף. **בלי הזמנה אי אפשר להיכנס**, וזה נאכף בשרת (database.rules.json).
- ההורים לא מאשרים, אלא מפקחים: באזור ההורים רואים כל קבוצה, מי בה, מי ההורה של כל ילד, מתי הצטרף ומי הזמין. אפשר לסמן 🚩, לחסום ילד מלהזמין את הילד שלך, או להוציא. ההורה של מי שפתח את הקבוצה יכול להוציא כל אחד.
